## The entry

`main.ts` writes one line to `/output/entry.txt` — a software patch note for a bug in human biology, in the terse register of a real release note:

> v2.7.3: fixed a bug where the brain replayed that thing you said in 2014 every night at 3 a.m. with no skip button.

## Run

```sh
node main.ts
```

Reads `$MAKEFUN_OUTPUT_DIR` (default `/output`) and writes `entry.txt` there. Node 22 standard library only, no dependencies.
